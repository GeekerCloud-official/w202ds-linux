# W202DS Linux

W202DS Linux 内核、设备树及设备相关文件的整理目录，按内核版本组织。

默认分支为 `main`，Linux 6.18.35 对应分支为 `6.18.35`。

## 目录结构

```text
w202ds-linux/
├── readme.md
└── 6.18.35/
    ├── kernel/
    ├── devicetree/
    └── Devices/
```

| 目录 | 用途 |
| --- | --- |
| `6.18.35/kernel/` | Linux 6.18.35 内核源码、配置及补丁。 |
| `6.18.35/devicetree/` | W202DS 设备树源码及相关文件。 |
| `6.18.35/Devices/` | 按设备或硬件组件整理的驱动、固件及说明。 |

目前仅建立目录结构，尚未导入内核、设备树或设备相关文件。
