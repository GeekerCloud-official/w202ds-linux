# w202ds-sensorhub-driver（运动、磁场与光线传感器）

```text
sensorhub/
├── build.mk
├── devicetree/
├── firmware/
├── README.md
└── source/
```

| 功能 | 可用性 | 问题描述 |
| --- | --- | --- |
| 加速度读取（LSM6DSOQ） | 原始数据可读 | 实际运动响应、坐标方向、单位及校准待验。 |
| 陀螺仪读取（LSM6DSOQ） | 原始数据可读 | 角速度响应、坐标方向、单位及校准待验。 |
| 磁场读取（MMC5603） | 三轴数据可读 | 指南针朝向与磁场校准待验。 |
| 环境光读取（LTR578） | 数据可读 | 实际光照响应、单位及校准待验。 |
| 自动旋转 | 待完成 | 尚无系统自动旋转验收结果。 |
| 自动亮度 | 待完成 | 尚无屏幕亮度联动验收结果。 |
| 连续缓冲采样 | 尚未实现 | 当前为 IIO 直接读取，尚无 IIO 缓冲采样。 |
| 冷启动与长期运行 | 待验证 | 尚无反复冷启动和长时间稳定性结论。 |
