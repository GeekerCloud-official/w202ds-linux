| 功能 | 可用性 | 问题描述 |
| --- | --- | --- |
| H.264 / AVC 硬件解码 | 已验证 | 450 帧（含 1080p）逐帧匹配软件参考（2026-11-05 验证）；依赖设备原厂专有用户态库。 |
| 解码后空闲省电 | 已验证 | 测试结束后进入 suspended；尚未覆盖长时间播放及反复启停。 |
| 普通播放器与浏览器硬件解码 | 待完成 | 通用 V4L2 及播放器、浏览器接入尚未验收。 |
| 视频编码 | 待验证 | 尚无编码功能验收结果。 |
| 其他视频格式 | 待验证 | 当前结果只覆盖 H.264 / AVC。 |

更新日期：2026-11-05
